# AI Chat (read-only Claude Code) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admins and superadmins chat with a read-only Claude Code from a new page in the VPS Monitor.

**Architecture:** New `chat.js` module (no dependencies) builds a per-user symlink sandbox of visible projects, spawns `claude -p` as the unprivileged user `claude-ro`, and streams the reply to the browser as server-sent events. `server.js` only computes the visible project list and routes `/api/chat` and `/chat`.

**Tech Stack:** Node >=18, plain JS, `node:test`, vanilla front-end.

**Spec:** `docs/superpowers/specs/2026-11-03-ai-chat-design.md`

## Global Constraints

- No new npm dependencies (`package.json` stays dependency-free).
- Roles allowed: `admin` and `superadmin` (`session.admin === true`); `viewer` gets 403.
- Claude tools: allow `Read,Grep,Glob`; deny `Bash,Edit,Write,NotebookEdit,WebFetch,WebSearch`.
- Limits: 1 running chat per user, 20 messages per hour per user, 120 s timeout.
- Message goes to the child on stdin, never argv. `sessionId` must match a UUID before use with `--resume`.
- Child env contains only `PATH`, `HOME`, `CLAUDE_CODE_OAUTH_TOKEN`. Token never sent to the browser or logged.
- Replies rendered with `textContent`, never `innerHTML`.
- Follow repo style: `'use strict'`, CommonJS, 2-space indent, Indonesian comments are fine, English UI text.

## Review Focus

- Empty, non-string or over-length (>4000 chars) message: 400, no child spawned.
- Malformed `sessionId` such as `--dangerously-skip-permissions`: 400, never reaches argv.
- Second request while the first is running, and the 21st request within an hour: 429.
- `SCAN_ROOT` entries that are files, dot-directories, or names with odd characters: skipped, never symlinked.
- Client closes the tab mid-stream: child killed, lock released, next request works.
- `claude` prints a non-JSON line or exits non-zero without a result: error event, no crash.

  - `client disconnect kills child and frees lock`: trigger `req` close while the fake bin sleeps; child pid is gone; a new `handleChat` for the same user is not 429.
